# 网易云音乐设置增强 (NCMWSE)

**Netease Cloud Music WEB Setting Enhancement**

一个用于网易云音乐网页版的用户脚本（UserScript）：把正在播放的歌曲信息同步到 **Windows 系统媒体控制（SMTC）**，并用可拖拽排序的片段模块**自定义网页标题**。

支持 ScriptCat、Tampermonkey、Violentmonkey 等主流脚本管理器。

```
// @name         网易云音乐设置增强(NCMWSE)
// @namespace    https://github.com/minecraftmc22/Netease_Cloud_Music_WEB_Setting_Enhancement
// @version      1.3.4
// @author       Minecraftmc22
// @license      MIT
// @match        *://music.163.com/*
// @match        *://*.music.163.com/*
```

---

## 功能一览

| 模块 | 说明 |
|---|---|
| **系统媒体（SMTC）** | 标题栏 / 歌手栏 / 专辑栏三行内容，全部由片段列表自由编排 |
| **网页标题** | 标签页标题自定义，片段可拖拽排序 |
| **片段类型** | 歌曲名、歌手、歌词、专辑、网站名称（网站名称为自定义文本） |
| **快速预设** | 一键套用整套配置（连翻译开关一起设好） |
| **独立翻译开关** | 系统媒体与网页标题各自的「歌词」片段分别控制是否带译文 |
| **导入 / 导出** | 配置导出为 JSON（复制或下载），也可从粘贴内容或文件导入 |
| **诊断信息面板** | 实时显示歌曲、歌曲 ID、歌词行数、播放进度、当前歌词，歌词不显示时看这里 |
| **专辑封面** | 可选是否向系统媒体发送封面图 |

### 内置预设

**系统媒体（SMTC）**

- `歌曲名 / 歌手` —— 标题栏显示歌曲名，歌手栏显示歌手（默认）
- `歌词 / 歌曲名 - 歌手` —— 标题栏显示当前歌词，歌手栏显示「歌曲名 - 歌手」

**网页标题**

- `歌曲名 - 歌手 - 网站名称` —— 与网易云原生标题样式一致
- `歌词(翻译) - 歌曲名 - 歌手`
- `歌词(翻译)`

带「翻译」字样的预设会自动打开对应的翻译开关；SMTC 预设未包含翻译则会将其关闭。套用后仍可在面板里手动微调。

## 安装

1. 安装脚本管理器扩展：[ScriptCat](https://scriptcat.org/) / Tampermonkey / Violentmonkey。
2. 新建脚本，把 `NCMWSE.user.js` 的内容整段粘贴进去，保存。
   - 也可以直接把 `.user.js` 文件拖进浏览器（前提是脚本管理器已开启「允许访问文件网址」）。
3. 打开 <https://music.163.com> 并开始播放，脚本会自动生效。

## 打开设置

脚本启动后有三种入口，任选其一：

1. **页面右下角齿轮按钮** —— 最直观，悬停变红，点击即开。
2. **快捷键 `Ctrl + Alt + S`**
3. **脚本管理器菜单** —— 扩展弹窗 → 找到本脚本 → 菜单 / ⋯ → 「显示设置」。

> 不想看到右下角按钮，可在面板里关掉「显示右下角设置按钮」，快捷键与脚本菜单仍然可用。

脚本菜单还提供：

- **显示设置**
- **立即重新同步** —— 强制刷新一次系统媒体元数据
- **清空歌词缓存并重试** —— 歌词获取异常时用

## 设置项说明

### 系统媒体（SMTC）

三个栏位独立编排，每栏都是一份「片段列表」：

| 栏位 | 对应系统媒体卡片的位置 |
|---|---|
| 标题栏 | 主标题（大字） |
| 歌手栏 | 副标题 |
| 专辑栏 | 专辑行 |

- 每栏可**增删片段**，并按住整行**上下拖动排序**。
- 三栏**共用一个片段连接符**：`空格 - 空格` / `· 间隔点` / `| 竖线` / 无分隔 / 自定义。
- 某栏清空 = 该栏不发送（标题栏清空时会兜底显示歌曲名，避免媒体卡片空白）。
- 空值片段自动跳过，不会留下多余分隔符（比如纯音乐无歌词时不会拖出一个孤零零的 ` - `）。

### 网页标题

- 开关「自定义网页标题」，**默认关闭**。关闭时不动页面标题；从开启切回关闭会自动还原站点原标题。
- 片段列表同样支持拖拽排序与增删，默认 `歌曲名 - 歌手 - 网站名称`。
- 「网站名称」是可编辑文本框（默认 `网易云音乐`），另外几种为动态值。
- 自带连接符设置与实时预览。

### 启用翻译

**两个开关完全独立**：

| 开关 | 作用范围 |
|---|---|
| 启用翻译?（系统媒体） | 只影响 SMTC / 系统媒体浮窗 |
| 启用翻译?（网页标题） | 只影响网页标题里的「歌词」片段 |

可以只让系统媒体带译文、标题不带，反之亦可。

译文的配对规则：**按时间戳与本句原文双向配对**——译文行的时间需贴近当前原文行，且反查该译文最近对应的原文必须就是当前这句。因此中英夹杂的歌曲唱到**没有译文的中文行**时，不会沿用上一句英文的翻译。

另外，若某首歌没有独立译文文件，而是把译文内嵌在 lrc 里与原文同时间戳（两行语种不同且含拉丁字母），脚本会自动识别第二条为译文。

### 导入 / 导出

面板底部两个按钮，操作在弹层内完成（全程无原生对话框）：

- **导出** —— 只读 JSON 文本框 + 复制到剪贴板 + 下载 `NCMWSE-config.json`，文件自带脚本名 / 版本 / 导出时间。
- **导入** —— 粘贴 JSON 或从文件选择，内容先写入草稿供你预览，点「保存并关闭」才真正生效；格式不合法会红字报错。

兼容两种格式：带 `{ "app": ..., "cfg": ... }` 包装的导出文件，或裸配置对象。

```json
{
  "app": "NCMWSE",
  "name": "网易云音乐设置增强(NCMWSE)",
  "version": "1.3.4",
  "exportedAt": "2026-10-13T08:30:00.000Z",
  "cfg": {
    "enabled": true,
    "showFab": true,
    "showArtwork": true,
    "showTranslation": false,
    "smtc": {
      "sep": " - ",
      "title":  [{ "type": "song",   "text": "" }],
      "artist": [{ "type": "artist", "text": "" }],
      "album":  [{ "type": "album",  "text": "" }]
    },
    "titleCfg": {
      "enabled": false,
      "showTranslation": false,
      "sep": " - ",
      "parts": [
        { "type": "song",   "text": "" },
        { "type": "artist", "text": "" },
        { "type": "site",   "text": "网易云音乐" }
      ]
    }
  }
}
```

### 诊断信息面板

打开设置拉到底，五行信息实时刷新：

```
歌曲：夜曲 / 周杰伦
歌曲 ID：1234567（来源：播放栏链接）
歌词：58 行已加载 · 翻译 12 行（本句已匹配）
播放进度：42.3 秒（audio 元素）
当前歌词：第 24 行 · 一群嗜血的蚂蚁
```

对照排查：

| 现象 | 可能原因 |
|---|---|
| 歌曲 ID 未获取到 | 页面结构改版，三重兜底（播放栏链接 → URL → 歌名搜索）都没命中 |
| 歌词未获取到但 ID 正常 | 该曲目本身无歌词（纯音乐），或接口返回空 |
| 翻译行数 0 | 该曲目没有译文文件 |
| 播放进度未获取到 | 时间源（`<audio>` → 播放栏时间文本）都失效 |
| 全部正常但媒体无歌词 | 系统媒体卡片未刷新，或该栏未放入「歌词」片段 |

## 原理

1. 读取网易云网页版（含同源 iframe）的播放信息：站点 `mediaSession.metadata` → 播放栏 DOM → `document.title` 三级兜底。
2. 歌词走网易云**同源接口** `/api/song/lyric` 与 `/api/song/detail`，拿 lrc、译文、封面、专辑。
3. 用页面 `<audio>` 的 `currentTime`（回退到播放栏时间文本）定位当前歌词行。
4. 组装结果写入 **Media Session API**，Windows 会把它同步到系统媒体控制（Win+G / 音量键弹窗 / 锁屏信息）。
5. 网页标题通过改写 `document.title` 实现。

几个实现要点：

- **劫持 `mediaSession.metadata` 的 setter**：站点写入的歌曲信息被截获作为权威数据源，脚本自己的写入走原生 setter，互不覆盖（否则站点每次刷新元数据都会把歌词模式顶掉）。
- **标题污染隔离**：分别记录「脚本写的标题」与「站点写的标题」，从标题解析歌名/歌手的兜底逻辑只认站点原文；关闭自定义标题时还原站点标题。
- **歌曲 ID 提取收紧**：只认路径带 `song` 的链接，显式排除 artist / playlist / album / dj / radio / toplist / user 等，避免把歌单 ID 当成歌曲 ID（这正是此前「歌名对、歌词空」的根因）。

## 配置迁移

`@namespace` 曾于 v1.3.1 从 `gtnetwork.top/ncm-smtc` 变更为 GitHub 仓库地址，因此：

- v1.3.1 → v1.3.2 时，脚本管理器会视为新脚本，列表里可能**同时存在新旧两条**（旧的需手动删除），且配置会重置为默认值。
- v1.3.2 之后 `@name` / `@namespace` 未再变动，升级不会再出现双条目。
- v1.3.3 及之前的「第一行 / 第二行」下拉框配置，在升级到 v1.3.4 后**会自动翻译**成对应的片段列表（含翻译开关），首次打开面板时会看到迁移结果，保存后才写入新结构。

## 常见问题

**Q：系统媒体卡片里没出现我正在播放的歌？**
A：需要页面处于**播放状态**，暂停时媒体卡片可能直接消失，这是 Windows 的行为。另外确认「启用显示增强」开关是打开的。

**Q：更新后看不到右下角按钮 / 设置入口？**
A：先按 F12 看 Console 有没有 `[NCMWSE] ... 已启动` 的日志。
- **有** → 脚本在跑，可能只是按钮被页面元素遮挡；
- **没有** → 检查脚本是否启用、当前网址是否为 `music.163.com`、`@match` 是否被改动。

**Q：标签页标题会随歌词滚动跳动？**
A：预期行为——标题里含「歌词」片段时就会这样。不想要就在标题片段里去掉「歌词」。

**Q：歌词一直不显示？**
A：打开设置看诊断面板。若「歌曲 ID」正常但「歌词」未获取到，换一首带歌词的歌验证；若 ID 一直拿不到，请把诊断信息与页面播放栏结构反馈。

**Q：翻译残留（唱到中文行还在显示上一句英文的译文）？**
A：v1.3.2 已修复，升级脚本后刷新页面即可。

## 兼容性

- 需要支持 `GM_getValue` / `GM_setValue` / `GM_registerMenuCommand` / `unsafeWindow` 的脚本管理器。
- 仅在顶层文档运行（`@noframes`），但会自动在同源 iframe 中查找播放元素。
- 网易云改版导致播放栏类名变化时可能抓不到歌名，届时需要补选择器。
